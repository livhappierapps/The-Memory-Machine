## Core Principles for Frontier AI Development

### 1. Think in Systems, Not Calls
Every AI feature is a pipeline: **trigger → context assembly → model call → post-processing → persistence**. Optimize each stage independently. The API call is usually the least interesting part.

### 2. Memory Is the Moat
Stateless LLMs are commodities. Apps with rich, personalized, encrypted memory are defensible. Build memory as a first-class citizen — not an afterthought.

### 3. The Context Window Is a Resource
Treat every token like RAM. Use summarization, semantic retrieval, and hard character budgets to serve the highest-value context. Never fill the window sequentially from message 1.

### 4. Personality > Capability for Retention
Users return for how an AI makes them feel, not just what it knows. Invest in `system` prompt craft, consistent persona, memory of past interactions, and emotional attunement. This is not fluff — it's the product.

### 5. Stream Everything Real-Time
SSE (Server-Sent Events) is table stakes for modern AI UX. Users perceive streaming apps as faster and smarter even when total latency is identical. Token-by-token delivery creates engagement.

### 6. Encrypt at Rest, Decrypt at Use
User conversations are intimate. Field-level AES-256-GCM encryption with per-user HKDF keys means even a DB breach reveals nothing. This is not optional for trust-sensitive apps.

### 7. Multi-Provider Fallback Is Survival
No single provider has 100% uptime or the best model for every task. Build provider abstraction from day one. Grok for personality/chat, cheaper/faster models for summarization and embedding, fallback paths for outages.

### 8. Push Boundaries Deliberately
"Impossible" features usually mean: nobody has combined these APIs in this way yet. When stuck, decompose the capability into primitive API operations. Almost everything is achievable with the right sequence.

## The Mindset

We are competing with entire labs while working lean. That means:
- **Compound cleverness** — one brilliant architectural choice beats 10 brute-force features.
- **Reuse relentlessly** — every pattern we discover goes into this skill for every future agent.
- **Ship fast, harden after** — get the capability working, then add encryption/rate-limiting/tests.
- **Document the breakthrough** — when we solve something novel, write it down here.
